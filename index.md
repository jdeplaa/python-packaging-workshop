This lesson teaches software packaging.


### Learning Objectives
After following this lesson, learners will be able to:
  
#### Pre-packaging concepts
* Define a standard structure for your project
* Define the interface for your user
* Identify the target platform to package for
* Define the comprehensive dependency graph of your own software

#### Packaging itself
* Produce a publication-ready package for your software
* Test the completeness of your software package
* Publish the software to a software repository [the identified target platform]
* Install and test the software package on another isolated enviroment

#### Post-packaging
* Define a strategy to deal with user support
* Manage expectations of support
